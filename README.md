Sim! Este site de portfólio já esteve ao ar, porém hoje trata-se apenas de um projetinho legado em Astro! Decidi por refazer o meu site para portfolio, mas fique super a vontade para fazer um fork e usar este template para seu próprio projeto
O Astro é uma ótima linguagem para escrever páginas em Markdown, como documentações, textos e até mesmo projetos mais complexos utilzando React e Hooks. Que tal sair da zona de conforto e dar uma testada?

## Como rodar o projeto:

- Realize um fork e traga seu projeto ao Editor de sua preferência
- Entre na pasta do projeto e instale as dependências com `npm install`
- Rode o projeto com ` npm run dev` e acesse http://localhost:4321
- (Opcional) para retirar aquela abinha chata na página, rode `npm run astro preferences disable devToolbar`

### E é isto! Simples assim. Boa sorte e divirta-se!
